{

  "message": "success",

실패 응답

{
  "code": "INVALID_STATUS_TRANSITION",
  "message": "올바르지 않은 상태 변경입니다.",
  "data": null

code 는 에러 코드 표의 값이다. HTTP 상태 코드와 함께 내려온다. 분기는 code 로 하고, message 는 그대로 노출해도 되는 한국어 문구다.

서버가 검증한다. 표에 없는 전이를 요청하면 400 INVALID_STATUS_TRANSITION 이 내려온다.

활동중단없음
  • 서류합격 에서 최종합격 으로 바로 보내면 400 이다. 면접합격 을 거쳐야 한다.
  • 역방향 전이는 어느 상태에서도 불가능하다. 면접합격 → 서류합격 되돌리기 없음.
  • 현재 상태와 같은 값을 보내면 아무 일도 일어나지 않고 200 이 내려온다. 메일도 나가지 않는다.

상태 변경이 성공하면 서버가 지원자에게 안내 메일을 자동 발송한다. 별도 호출은 필요 없다.

기수 활동 종료일

기수에 activityEndAt 필드가 추가됐다. 이 시각이 지나면 기수가 자동으로 CLOSED 가 되고, 그 기수의 활동중 지원자가 모두 활동완료 로 전환된다. 판정은 한국 시간 매일 자정에 도는 스케줄러가 하므로, 종료일 당일이 아니라 그 다음 자정에 반영된다.

어드민이 기수 상태를 직접 CLOSED 로 바꿔도 같은 전환이 일어난다. 단 ACTIVE 기수를 닫을 때만이다. UPCOMING·RECRUITING 기수를 닫는 건 지원자 상태를 건드리지 않는다.

POST /api/v1/admin/cohorts
PATCH /api/v1/admin/cohorts/{id}

권한

계정관리 · 운영자

Request Body (추가 필드)

필드타입필수설명
activityEndAtstring | null (ISO 8601)-활동 종료일. 생략하면 기존 값 유지, null 을 보내면 자동 종료 예약 해제. 한 번도 설정하지 않은 기수는 자동 종료 대상이 아니다
 
// 자동 종료 예약
{
  "activityEndAt": "2026-06-30T23:59:59Z"
}

// 예약 해제
{
  "activityEndAt": null
}

Response (추가 필드)

필드타입설명
activityEndAtstring | null설정되지 않았으면 null

Error

HTTPcode발생 조건
400INVALID_ACTIVITY_END_DATEactivityEndAt 이 모집 종료일보다 빠름
400ACTIVITY_END_DATE_IN_PASTactivityEndAt 이 과거. 이미 끝난 기수는 상태를 CLOSED 로 바꿔서 닫는다
  • 기수를 CLOSED 로 바꾸는 요청은 그 기수의 활동중 지원자 상태를 함께 바꾼다. 되돌릴 수 없으므로 확인 절차를 두는 편이 안전하다.
  • 활동중단 인 지원자는 전환 대상이 아니다.
  • 이미 지난 activityEndAt 을 가진 기수라도 이름·일정 등 다른 항목 수정은 막히지 않는다. 과거 날짜 검사는 activityEndAt 을 실제로 보낼 때만 돈다.
  • 활동 상태 전환(활동중·활동완료·활동중단)에는 지원자 안내 메일이 나가지 않는다. 메일은 전형 발표 5종에만 발송된다.
